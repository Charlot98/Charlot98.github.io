犬猫心脏超声中的Tei 指数（MPI）

Tei 指数，也叫 MPI（Myocardial Performance Index，心肌性能指数/心肌做功指数），是心脏超声中一个非常实用的综合功能指标。它的价值在于：不像 EF那样主要反映收缩功能，也不像单一舒张参数那样只关注舒张过程，Tei 指数能够在一个数值中同时反映心脏的收缩与舒张表现，因此在犬猫及其他小动物心脏超声评估中具有较高参考意义。从本质上讲，Tei 指数衡量的是“心脏为了完成一次有效射血，花在非射血阶段的时间，相对于真正射血时间所占的比例”。如果心脏在一次心动周期中，准备收缩和完成舒张恢复所花费的时间变长，而真正把血液射出的时间相对变短，那么这个指数就会升高。也正因为如此，Tei 指数越高，通常提示整体心肌功能越差。

01 Tei 指数的基本原理

理解 Tei 指数，关键在于先理解它涉及的三个时间段： 等容收缩时间（ICT，isovolumic contraction time） 心室开始收缩后，房室瓣已经关闭，但半月瓣尚未开放。此时心室压力正在升高，但尚未发生血液射出，因此这段时间属于“收缩准备阶段”。 射血时间（ET，ejection time） 当心室压力超过主动脉或肺动脉压力后，半月瓣开放，血液被真正射出。这一阶段是心脏完成有效泵血的核心时间段。 等容舒张时间（IRT，isovolumic relaxation time） 射血结束后，半月瓣关闭，但房室瓣尚未开放。此时心室开始舒张和压力下降，但还没有开始充盈，这段时间属于“舒张恢复阶段”。

Tei 指数的公式为：

MPI = (ICT + IRT) / ET

也可以写成：

MPI = (a - b) / b

其中：

  • a 表示房室瓣关闭到再次开放之间的总时间；
  • b 表示射血时间 ET。

由于：

a = ICT + ET + IRT

所以：

a - b = ICT + IRT

因此最终可写为：

MPI = (ICT + IRT) / ET

用更直白的话说，Tei 指数比较的是“非有效射血时间”与“有效射血时间”的比例。分子越大、分母越小，说明心脏整体效率越差。

02 Tei 指数反映的功能意义

Tei 指数之所以重要，是因为它并不是单纯反映心脏某一个方面的功能，而是同时受到收缩功能和舒张功能的影响。

对收缩功能的反映 当心室收缩能力下降时，常可见：

  • 等容收缩时间延长
  • 射血时间缩短 这样就会导致 MPI 升高。

对舒张功能的反映 当心室舒张功能变差、舒张减慢时，常可见：

  • 等容舒张时间延长 这同样会使 MPI 升高。

因此，Tei 指数可以理解为一个“整体心功能效率指标”。它不能完全替代其他参数，但可以作为一个综合性较强的辅助指标，用于评估病患心肌整体表现。

03 如何理解 Tei 指数的高低

临床解释 Tei 指数时，最核心的原则是： Tei 指数越高，通常表示整体心肌功能越差。

原因在于：

  • 心脏花在等容收缩和等容舒张上的时间变长
  • 真正完成射血的时间变短 这意味着心脏“准备和恢复”的过程占比增大，而“真正工作”的效率下降。

可以用一个简单类比帮助理解：把心脏想象成一个水泵。若这个水泵每次工作时，预压准备很久，卸压恢复也很久，而真正抽水的时间反而缩短，那么它整体效率就会下降。Tei 指数正是从这个角度来衡量心脏工作状态。

Tei 指数在超声中的测量方法

在心脏超声检查中，Tei 指数通常可以通过两类方法测得： 脉冲多普勒法（PW Doppler） 通过血流频谱测量：

  • 房室瓣流入相关时间参数
  • 主动脉或肺动脉射血时间 然后带入公式进行计算。

组织多普勒法（TDI） 通过瓣环或局部心肌组织运动频谱来测定各时间间隔，常见测量部位包括：

  • 二尖瓣环
  • 三尖瓣环 TDI 法的优势在于，某些情况下可以在同一个心动周期中更方便地获得多个时间参数，因此在小动物心超评估中较为常用。尤其在评估局部心肌运动和整体时间关系时，TDI 与 MPI 的结合很有实践意义。

05 Tei 指数与 EF 的区别

在兽医临床中，很多医生首先熟悉的是 EF（射血分数）。EF 当然很重要，但它与 Tei 指数关注的重点并不完全相同。 EF 主要反映：

  • 左心室收缩功能
  • 一次收缩中泵出血液的比例 而 Tei 指数更关注：
  • 收缩与舒张的综合表现
  • 心脏完成一次有效泵血的整体时间效率 因此，EF 正常并不代表 Tei 指数一定正常。某些早期功能异常，尤其是舒张异常或整体效率下降的情况，可能在 EF 尚未明显异常时，就已经表现为 MPI 升高。 换句话说，EF 更像是在看“泵得多不多”，而 MPI 更像是在看“这次泵血过程的整体效率好不好”。

06 Tei 指数在兽医临床中的应用价值

在兽医心脏超声中，Tei 指数常可用于以下场景： 评估左心室整体功能 对于存在心肌病、慢性容量负荷异常或疑似早期心功能损害的病患，MPI 可作为综合参考指标。 评估右心室功能 Tei 指数在右心功能评估中尤其有价值。对于疑似肺动脉高压、右心负荷增加或右心功能异常的病患，右心 MPI 常可提供补充信息。 监测病程和治疗反应 在一些慢性心脏疾病病患中，MPI 可用于随访整体心肌功能变化，辅助观察病情进展及治疗后的功能改善情况。

作为 TDI 评估体系中的一部分 如果临床上已进行组织多普勒检查，那么将其与 MPI 结合，可进一步提高对心肌整体功能状态的判断深度。

07 Tei 指数的局限性

虽然 Tei 指数有重要价值，但它并不是万能指标，解读时应注意以下局限： 受心率和节律影响 如果病患存在：

  • 心律不齐
  • 心动过速
  • 明显传导异常 则时间间隔测量可能不稳定，从而影响 MPI 的准确性。

受瓣膜病影响 明显瓣膜病变可能改变流入、流出及等容期时间，因此在解读时必须结合瓣膜结构与血流信息综合判断。

受前负荷和后负荷变化影响 例如：

  • 血容量变化
  • 血压变化
  • 肺动脉压力变化 都可能使 MPI 发生波动，因此它不是绝对独立于负荷条件的指标。

不能脱离整体超声结果单独解释 Tei 指数只能作为整体超声评估的一部分，不能单独作为诊断结论。临床上仍需结合以下 进行综合判断：

  • EF 或 FS
  • E/A
  • E/e'
  • TDI 各项参数
  • 心腔大小
  • 壁运动情况
  • 瓣膜结构与反流情况
  • 临床症状与体征

08 临床理解要点

对于兽医师而言，掌握 Tei 指数时可以抓住以下几个核心点：

  1. Tei 指数是综合指标，不仅看收缩，也看舒张。
  2. Tei 指数越高，通常提示整体心功能越差。
  3. 公式本质是“非射血时间 / 射血时间”。
  4. 它适合作为整体功能参考，而不是替代所有其他心超参数。
  5. 在右心功能评估及 TDI 相关分析中，Tei 指数尤其值得关注。

09 总结

Tei 指数（MPI）是心脏超声中一个重要的综合功能指标，其核心思想是：比较心脏在一个心动周期内“非射血时间”与“有效射血时间”的比例。它能够同时反映收缩与舒张功能，因此比单纯的收缩指标更全面。 其公式为：

MPI = (ICT + IRT) / ET

当等容收缩时间延长、等容舒张时间延长，或射血时间缩短时，MPI 会升高。一般而言，MPI 越高，提示整体心肌性能越差。 在兽医临床中，Tei 指数适用于左、右心整体功能评估，也可用于病程监测与 TDI 联合分析。但在实际应用中，应始终结合其他超声参数及病患整体临床情况综合解读，避免孤立使用。 一句话概括：

Tei 指数衡量的是“心脏为了完成一次有效泵血，花了多少无效准备与恢复时间，相对于真正射血时间的比例”；比例越大，通常说明整体心功能越差。
