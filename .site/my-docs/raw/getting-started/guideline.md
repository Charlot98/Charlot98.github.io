# 编者指引

> 

## 标题

文章标题、作者姓名（可以用统一网名）、编辑时间

## 简介

简洁的语言界定主题的范围

## 内容

- 直奔主题
- 关注主要问题，不要关注历史背景或老式的影像学检查
- 以临床医生的角度思考并解决问题

  - 临床医生想治疗什么？
  - 影像医生在诊断过程中的作用？
- 使用 <span className="text-primary">

**精简**

</span>

 的文字，图片、文字配合

## 图表

- 尽量简洁的图标展示内容
- 原图请尽量高清，图片会在排版时压缩
- 表格可以使用文本格式，也可以图片，无严格要求

## 参考

- 列一份主要参考文献或书籍的清单
- 参考文献无需在正文中引用
