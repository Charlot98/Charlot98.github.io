# Mavacamten

> 

## Mavacamten

- 通用名：玛伐凯泰、马瓦卡坦
- 商品名：Camzyos（可心欧、迈凡妥）

## 临床使用玛伐凯泰

- 统一初始用药方案为0.25片每日，2-4周复查
- 纳入标准：心肌广泛肥厚超过7.5mm的SAM征猫，或广泛性肥厚超过9mm，或3个月复查心肌厚度增加≥0.5mm
- 排除标准：收缩功能性下降较明显，FS＜30%
- 统一在2D乳头肌切面短轴下测量厚度，局灶肥厚的需标注厚度
- 4周无效考虑停药
- 复查项目：心超+左心高阶、BNP
- 副作用：有较低概率引起收缩功能下降明显。
